# Fokus auf Frontend-/UX-UI-Modernisierung statt Neuentwicklung

Die Leistungen-Section bot bisher drei Bausteine an, darunter "Apps & Plattformen" (komplette Neuentwicklung digitaler Produkte von Grund auf). Dieser Punkt entfällt als eigenständiges Angebot: das tatsächliche Angebot besteht aus zwei Säulen — Frontend-Entwicklung / UX-UI-Modernisierung bestehender Apps, Plattformen und Tools, sowie gezielte Beratung & Konzeption dazu. Grund: schärfere Positionierung auf den tatsächlichen Kernfokus (Frontend/UX/UI), statt ein breiteres Neuentwicklungs-Versprechen zu machen, das nicht der eigentlichen Arbeit entspricht.

**Konsequenz:** Anfragen für komplette Neuentwicklungen "von Grund auf" fallen künftig außerhalb des beworbenen Angebots. Kommt so eine Anfrage trotzdem rein, lässt sie sich im Rahmen von Beratung & Konzeption aufnehmen, ist aber kein aktiv beworbener Leistungsbaustein mehr.
